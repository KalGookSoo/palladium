# 샘플 프로젝트와 온보딩 유즈케이스

## 목적

처음 쓰는 사용자가 5분 안에 "배치 → 편집 → 내보내기"를 한 바퀴 해 보며 화면에 드러나지 않는 기능(우클릭, 수식키 끌기, 레인 두 번 클릭, 한 글자 단축키)을 익힌다(#63).

## 사용자 흐름

1. 시작 창에 "샘플 프로젝트로 둘러보기" 버튼이 있다. 도움말 메뉴에서도 열 수 있다. 자동으로 열지는 않는다.
2. 누르면 "palladium 둘러보기" 프로젝트가 만들어지고 열린다. 짧은 영상 3개(가로 2·세로 1), 로고 이미지 1개, 배경음악 1개가 미디어 패널에 있고, 처음 실행 때 앱이 직접 만든 파일이라 바로 재생된다.
3. 편집 창에 "둘러보기" 할 일 목록이 뜬다(닫았다가 도움말 메뉴에서 다시 연다). 단계마다 한 줄 설명·단축키·"보여줘" 버튼(해당 패널·메뉴를 강조)이 있다.
   1. 원본을 타임라인으로 끌어다 놓기
   2. 재생 헤드에서 클립 자르기(⌘B)
   3. 클립 끝을 끌어 트림하기
   4. 두 클립 사이에 디졸브 넣기(뒤 클립 우클릭)
   5. 자막 넣기(T)
   6. 영상 소리 줄이기(인스펙터 > 오디오)
   7. 로고를 위 트랙에 얹고 크기 줄이기
   8. 얼굴 가리기(마스크 레인 두 번 클릭)
   9. 내보내기(⌘E)
4. 사용자가 실제로 해내면 프로젝트 상태를 보고 자동으로 체크된다(예: 자막이 하나 생기면 5번 완료).
5. 다 끝내면 "이제 내 영상으로 시작하기"로 새 프로젝트를 만든다. 샘플 프로젝트는 시작 창 목록에 남고 지울 수 있다. 다시 둘러보면 새 샘플 프로젝트를 만든다.

## 수용 기준

- 네트워크 없이 동작한다.
- 단계 완료는 화면 조작이 아니라 프로젝트 상태(편집기 쿼리)로 판단해, 단축키·메뉴 어느 쪽으로 해도 체크된다.
- 단계 설명과 단축키는 도움말·단축키 목록(`HelpContent`, `ShortcutGuide`)과 같은 출처를 써 문구가 어긋나지 않는다.
- 둘러보기 목록은 편집을 막지 않고, 닫아도 진행 상황은 그 프로젝트에 남는다.

## 결정 사항

- 샘플 미디어는 앱에 넣지 않고 처음 쓸 때 만든다(색 배경 위 움직이는 도형·글자 영상, 단순 화음 배경음악, 로고 PNG). 앱 크기가 늘지 않고 저작권 걱정이 없으며 오프라인이 보장된다. 실제 촬영본으로 바꾸고 싶으면 나중에 번들로 교체한다.
- 화면 요소를 가리키는 말풍선(코치마크)은 쓰지 않는다. 기본 분할 뷰·인스펙터 구조에서 위치가 바뀌면 깨지기 쉽다. "보여줘"는 해당 패널을 열고 선택·강조하는 정도로 한다.
- 지금의 디버그 샘플 데이터(없는 경로를 가리키는 원본)는 둘러보기 프로젝트로 대신한다. 디버그 메뉴의 "샘플 데이터 넣기"는 뺐다(`SampleData`는 테스트용으로 남는다).
- 구현(#63):
  - 샘플 미디어는 `Application Support/palladium/Samples`(앱 샌드박스 컨테이너 안)에 처음 한 번 만들고, 파일이 남아 있으면 다시 만들지 않는다. 영상은 그라데이션 배경 위 제목 글자·움직이는 노란 원·시각 글자(바다·도시 1280×720 6초, 세로 720×1280 5초, 30fps H.264), 로고는 투명 배경 600×600 PNG, 배경음악은 C·Am·F·G 화음 16초 AAC다. 만드는 데 몇 초 걸려 시작 창에 "샘플 영상을 만드는 중…"을 띄운다.
  - 프로젝트는 원본 5개를 "샘플" 폴더에 담고 시퀀스는 비워 둔다 — 배치부터 해 보게 하기 위해서다.
  - 시작 창: 목록이 비면 안내 가운데에, 목록이 있으면 아래 오른쪽에 "샘플 프로젝트로 둘러보기" 버튼. 도움말 메뉴 "샘플 프로젝트로 둘러보기…"는 시작 창을 열어 같은 일을 한다.
  - 할 일 목록은 미리보기 왼쪽 위에 떠 있는 카드다(편집을 막지 않음). 접기(▾)·닫기(✕), 닫으면 도움말 메뉴 "둘러보기 목록 보기"로 다시 연다. 지금 할 단계만 설명과 "보여줘"를 펼친다.
  - "보여줘": 원본 단계는 미디어 패널을 열고 그 원본(로고 단계는 로고)을 고른다, 타임라인 단계는 타임라인을 펴고 키를 받게 한다, 소리 단계는 인스펙터를 연다, 내보내기는 내보내기 창을 바로 연다.
  - 완료 판단(`TourStep.isCompleted`): 배치=클립이 있음, 자르기=같은 원본의 두 클립이 원본에서 이어지는 구간을 나눠 가짐, 트림=원본 처음·끝이 빠졌는데 그 자리를 같은 원본 클립이 잇지 않음(자르기만 한 조각과 구분), 전환=전환이 있는 클립, 자막=자막이 있음, 소리=영상 클립 음량 < 100%거나 음소거, 로고=메인(맨 아래)이 아닌 영상 트랙의 이미지 클립을 100%보다 작게, 마스크=마스크가 있음, 내보내기=그 프로젝트에서 내보내기를 끝냄.
  - 둘러보기 프로젝트 여부·내보내기 기록·목록 닫음은 프로젝트 내용이 아니라 안내 상태라 앱 설정(`TourProgress`, UserDefaults)에 프로젝트 ID로 둔다 — 저장하지 않은 변경·실행 취소를 남기지 않는다.
  - 다 끝내면 "이제 내 영상으로 시작하기"가 시작 창을 열어 새 프로젝트 이름을 묻는다.

## 관련 커맨드/쿼리

- 커맨드: `SampleProjectFactory.makeTourProject(using:)` — 샘플 미디어(`SampleMediaGenerator`)를 앱 컨테이너에 만들고 프로젝트를 저장소에 만든다.
- 쿼리: `TourStep.isCompleted(in: Project, exported: Bool) -> Bool` — 단계별 완료 판단.
- 진행 기록: `TourProgress`(둘러보기 프로젝트·내보내기·목록 닫음).
