# 샘플 프로젝트와 온보딩 유즈케이스

## 목적

처음 쓰는 사용자가 5분 안에 "배치 → 편집 → 내보내기"를 한 바퀴 해 보며 화면에 드러나지 않는 기능(우클릭, 수식키 끌기, 레인 두 번 클릭, 한 글자 단축키)을 익힌다(#63).

## 사용자 흐름

1. 시작 창에 "샘플 프로젝트로 둘러보기" 버튼이 있다. 도움말 메뉴에서도 열 수 있다. 자동으로 열지는 않는다.
2. 누르면 "palladium 둘러보기" 프로젝트가 만들어지고 열린다. 짧은 영상 3개(가로 2·세로 1), 로고 이미지 1개, 배경음악 1개가 미디어 패널에 있고, 처음 실행 때 앱이 직접 만든 파일이라 바로 재생된다.
3. 편집 창에 "둘러보기" 할 일 목록이 뜬다(닫았다가 도움말 메뉴에서 다시 연다). 단계마다 한 줄 설명·단축키·"보여줘" 버튼(해당 패널·메뉴를 강조)이 있다.
   1. 원본을 타임라인으로 끌어다 놓기
   2. 재생 헤드에서 클립 자르기(⌘B)
   3. 클립 끝을 끌어 트림하기
   4. 두 클립 사이에 디졸브 넣기(뒤 클립 우클릭)
   5. 자막 넣기(T)
   6. 영상 소리 줄이기(인스펙터 > 오디오)
   7. 로고를 위 트랙에 얹고 크기 줄이기
   8. 얼굴 가리기(마스크 레인 두 번 클릭)
   9. 내보내기(⌘E)
4. 사용자가 실제로 해내면 프로젝트 상태를 보고 자동으로 체크된다(예: 자막이 하나 생기면 5번 완료).
5. 다 끝내면 "이제 내 영상으로 시작하기"로 새 프로젝트를 만든다. 샘플 프로젝트는 시작 창 목록에 남고 지울 수 있다. 다시 둘러보면 새 샘플 프로젝트를 만든다.

## 수용 기준

- 네트워크 없이 동작한다.
- 단계 완료는 화면 조작이 아니라 프로젝트 상태(편집기 쿼리)로 판단해, 단축키·메뉴 어느 쪽으로 해도 체크된다.
- 단계 설명과 단축키는 도움말·단축키 목록(`HelpContent`, `ShortcutGuide`)과 같은 출처를 써 문구가 어긋나지 않는다.
- 둘러보기 목록은 편집을 막지 않고, 닫아도 진행 상황은 그 프로젝트에 남는다.

## 결정 사항

- 샘플 미디어는 앱에 넣지 않고 처음 쓸 때 만든다(색 배경 위 움직이는 도형·글자 영상, 단순 화음 배경음악, 로고 PNG). 앱 크기가 늘지 않고 저작권 걱정이 없으며 오프라인이 보장된다. 실제 촬영본으로 바꾸고 싶으면 나중에 번들로 교체한다.
- 화면 요소를 가리키는 말풍선(코치마크)은 쓰지 않는다. 기본 분할 뷰·인스펙터 구조에서 위치가 바뀌면 깨지기 쉽다. "보여줘"는 해당 패널을 열고 선택·강조하는 정도로 한다.
- 지금의 디버그 샘플 데이터(없는 경로를 가리키는 원본)는 둘러보기 프로젝트로 대신한다.

## 관련 커맨드/쿼리

- 커맨드: `SampleProjectFactory.makeTourProject(using:)` — 샘플 미디어를 앱 컨테이너에 만들고 프로젝트를 저장소에 만든다.
- 쿼리: `TourStep.isCompleted(in: Project) -> Bool` — 단계별 완료 판단.
