# 자막 삽입 유즈케이스

## 목적

사용자는 타임라인의 특정 구간에 자막 텍스트를 수동으로 붙이고, 필요하면 외부 자막 파일을 가져오거나 내보낸다.

## 사용자 흐름

1. 사용자가 타임라인에서 자막을 넣고 싶은 구간을 선택하고 텍스트를 입력한다.
2. 자막의 시작/종료 시점을 드래그하거나 정밀 입력으로 조정한다.
3. 미리보기에서 자막이 실제로 어떻게 보일지(위치/글꼴/크기) 바로 확인한다.
4. 이미 만든 SRT 등 외부 자막 파일이 있으면 통째로 가져와 타임라인에 반영한다.
5. 완성된 자막을 SRT 등 표준 포맷으로 내보내 다른 곳에서도 재사용한다.

## 수용 기준

- 원하는 시간 구간에 텍스트를 입력해 자막으로 추가할 수 있다.
- 자막의 시작/종료 시점을 자유롭게 조정할 수 있다.
- 미리보기에서 자막 스타일(글꼴, 크기, 위치, 색상 등 기본 범위)을 확인할 수 있다.
- SRT 파일을 가져오면 타임코드와 텍스트가 정확히 타임라인에 매핑된다.
- 자막을 SRT로 내보내면 다른 플레이어에서 열어도 동일한 타이밍으로 보인다.

## 결정 사항

- 자막은 원본 클립이 아니라 **최종 영상(시퀀스)의 시간**에 붙는다. 클립을 옮기거나 지워도 자막은 그 시각에 남는다. 그래서 클립 인스펙터의 "자막" 탭은 없앴다(#3 정리 중).
- 자막은 타임라인의 **자막 트랙**(눈금자 바로 아래, 시퀀스마다 하나)에 시작·끝이 있는 블록으로 놓고, 자막 블록을 고르면 인스펙터에 글자·스타일·시간을 보여준다(#4).
- 추가: 자막 트랙을 두 번 클릭하거나 우클릭, 또는 T. 재생 헤드부터 기본 3초 길이로 두고 바로 골라 인스펙터에서 글자를 입력한다.
- 시간 조정: 블록을 끌어 옮기고 양 끝을 끌어 시작·끝을 바꾼다(클립 경계·재생 헤드에 붙는다). 인스펙터에서 초 단위로도 입력한다. 최소 길이는 0.1초, 시작은 0초 이전으로 가지 않는다.
- 스타일 범위: 크기(24~120, 화면 짧은 변 1080 기준), 위치(위·가운데·아래), 색(흰색·노란색), 반투명 검은 배경 상자 켜기/끄기. 글꼴은 Apple SD 산돌고딕 Neo Bold 하나로 고정한다. 외곽선·자유 위치는 넣지 않는다.
- 긴 글자는 화면 너비의 90% 안에서 자동 줄바꿈하고, 줄바꿈 문자로 직접 여러 줄을 만든다.
- 겹치는 자막은 막지 않고 함께 그린다(같은 위치면 나중에 시작한 자막이 위). 별도 경고는 두지 않는다.
- 그리기: 미리보기와 내보내기가 같은 합성기(`LayerCompositor`)에서 Core Text로 그려 결과물에 박는다(번인). 클립이 없는 구간의 자막도 검은 화면 위에 보이고, 자막만 있는 시퀀스도 내보낼 수 있다.
- SRT: 파일 > 자막 가져오기(SRT)는 현재 시퀀스에 더하고(기존 자막은 그대로), 파일 > 자막 내보내기(SRT)는 시작 시각 순으로 번호를 매겨 UTF-8로 저장한다. 타임라인 길이를 넘는 타임코드도 그대로 가져온다(시퀀스 길이가 늘어난다). 형식이 틀린 항목은 건너뛰고, 스타일은 기본값이다. 소수점(`.`) 밀리초와 CRLF 줄바꿈도 읽는다.
- Delete(⌫)는 고른 자막을 지우고, Esc는 자막 선택을 푼다. 클립과 자막은 함께 고르지 않는다.

## 엣지 케이스

- 두 자막의 시간 구간이 겹치면 어떻게 표시하는가(동시 표시 vs 겹침 불가 처리).
- 가져온 SRT 파일의 타임코드가 현재 타임라인 길이를 벗어나면 어떻게 되는가.
- 자막 텍스트가 화면 밖으로 넘치는 경우(긴 텍스트) 자동 줄바꿈 처리.

## 관련 커맨드/쿼리

- 커맨드(`ProjectEditor`): `addSubtitle(at:)`, `updateSubtitle(_:text:style:)`, `setSubtitleRange(_:start:end:)`, `deleteSubtitle(_:)`, `importSubtitles(fromSRT:)`
- 쿼리: `currentSubtitlesSRT`(SRT 내보내기 내용), `SubtitleFile.parseSRT(_:)`/`makeSRT(_:)`

## 미정 사항

- 자동 음성 인식 기반 자막 생성(트랜스크립트 기반 편집)은 [보류(추후 논의) 기능](../video-editing-functional-spec.md#보류추후-논의-기능)으로 이번 범위에서 제외
- 모션 그래픽 템플릿 기반 자막 스타일 재사용도 같은 이유로 이번 범위에서 제외
