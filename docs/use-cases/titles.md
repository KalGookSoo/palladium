# 타이틀 유즈케이스

## 목적

자막과 별개로 오프닝 제목·설명 문구 같은 꾸민 글자를 화면 아무 곳에 얹는다(#76).

## 사용자 흐름

1. 재생 헤드를 둘 곳에 놓고 타임라인 메뉴 > 재생 헤드에 타이틀 추가(⌃T)를 누른다.
2. 맨 위 영상 트랙에 5초짜리 "제목" 타이틀 클립이 생기고, 골라진 채 인스펙터가 열린다.
3. 인스펙터 영상 탭 "타이틀" 섹션에서 글자·크기·글꼴·굵기·글자색·외곽선·그림자·배경을 바꾼다.
4. 미리보기 테두리로 옮기고 키우고 돌리며(트랜스폼), "페이드 인·아웃 넣기"로 나타나고 사라지게 한다.

## 결정 사항(#76)

- 타이틀은 **영상 트랙의 클립**이다(자막처럼 결과물 시간 레인이 아니다). 그래서 트림·이동·분할·복사·전환·트랜스폼·키프레임(#67)·색보정을 그대로 쓴다. 원본 파일이 없어 클립이 글자와 모양(`Clip.title: TitleText`)을 갖고, 원본 ID는 프로젝트 원본 목록에 없는 고정 값(`Clip.titleAssetID`)이다. 미디어 패널에는 항목이 생기지 않는다.
- 놓는 자리: 맨 위 영상 트랙의 재생 헤드(삽입 규칙대로 경계에 끼우고 뒤 클립을 민다). 영상 트랙이 하나면 그 트랙(메인)에 들어가 오프닝 제목이 되고, 영상 위에 겹치려면 사용자가 트랙 이름 우클릭으로 영상 트랙을 먼저 만든다 — "새 트랙은 사용자가 직접 만든다"는 굳은 결정을 지키기 위해서다. 영상 트랙이 하나도 없을 때만 새로 만든다(원본 배치와 같은 규칙).
- 크기 기준: 글꼴 크기는 화면 짧은 변 1080 기준 포인트(자막과 같음, 24~400). 화면 위 크기는 글자 상자의 원래 크기에 트랜스폼 배율을 곱한다 — 영상·이미지처럼 화면에 맞춰 늘리지 않는다(글자가 화면을 꽉 채우지 않게). 미리보기 테두리도 그 상자 크기로 그린다.
- 모양: 여러 줄 가운데 맞춤, 너비는 화면의 90%에서 줄 바꿈. 외곽선(0~20pt, 글자를 채운 채 바깥선), 그림자(켜고 끔), 배경 상자(색·불투명도, 둥근 모서리). 글자가 비면 "제목"으로 둔다(보이지 않는 클립이 되지 않게). 이 Mac에 없는 글꼴은 기본 글꼴로 그린다.
- 페이드 인·아웃: "페이드 인·아웃 넣기"가 불투명도 키프레임 네 개(처음 0 → 0.5초 뒤 지금 값 → 끝 0.5초 전 지금 값 → 끝 0)를 넣는다. 길이는 클립의 4분의 1을 넘지 않는다. 트랜스폼 키프레임이 이미 있으면 덮지 않도록 꺼진다. 타이틀이 아닌 클립에도 쓸 수 있다.
- 단축키 ⌃T는 Final Cut의 기본 타이틀 키를 따랐다.
- 그리기는 합성기(`TitleRenderer` → `LayerCompositor`)라 미리보기·내보내기가 같다. 글자 이미지는 캐시해 키프레임으로 움직여도 다시 그리지 않는다.
- 영속화: 클립 레코드 `titleData`(JSON, 옵셔널).
- 하지 않는 것: 타이틀 템플릿·움직이는 글자 효과(타자기 등), 글자 한 자씩 꾸미기, 미디어 패널의 타이틀 항목.

## 관련 커맨드/쿼리

- 커맨드: `ProjectEditor.addTitle(at:)`, `setTitle(_:for:)`, `addFade(to:duration:)`.
- 도메인: `TitleText`, `Clip.makeTitle(_:at:)`, `Clip.addFade(duration:)`, `ClipTransform.frame(naturalSize:in:)`.
