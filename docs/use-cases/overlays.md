# 오버레이 및 마스킹 유즈케이스

## 목적

사용자는 메인 영상 위에 이미지/스티커나 보조 영상(PIP)을 고정된 위치에 얹거나, 얼굴 등 특정 영역만 가리는 정적 마스킹(모자이크·블러)을 적용한다. 피사체를 따라 움직이는 동적 트래킹은 우선순위를 낮춰 별도로 다룬다([보류(추후 논의) 기능](../video-editing-functional-spec.md#보류추후-논의-기능) 참고).

## 사용자 흐름

1. 사용자가 이미지 파일, 스티커, 또는 보조 영상 클립을 오버레이용 트랙에 추가한다.
2. 오버레이의 위치·크기·불투명도를 조정한다(기본 트랜스폼 재사용).
3. 오버레이가 표시될 시간 구간을 타임라인에서 지정한다 — 보조 영상이면 자체 in/out 트림도 가능하다.
4. 얼굴 등 가리고 싶은 영역이 있으면, 화면의 고정된 사각형/원형 영역을 지정해 정적 마스킹(블러·모자이크)을 적용한다.
5. 미리보기에서 오버레이/마스킹이 메인 영상과 합성된 결과를 확인한다.

## 수용 기준

- 이미지/스티커를 영상 위에 고정 위치·크기·불투명도로 얹을 수 있다.
- 보조 영상(PIP)도 같은 방식으로 얹을 수 있고, 자체 재생 구간(트림)을 가진다.
- 정적 마스킹 영역은 지정된 시간 구간 동안 화면의 같은 위치에 고정 유지된다 — 피사체를 따라가지 않는다.
- 마스킹 영역 안에는 블러·모자이크 등 필터 이펙트를 선택해 적용할 수 있다.
- 오버레이/마스킹 모두 비파괴적이다 — 언제든 위치·크기·시간 구간을 다시 조정할 수 있다.

## 엣지 케이스

- 화면비 프리셋을 바꾸면(16:9 → 9:16 등) 오버레이/마스킹의 고정 위치가 어떻게 재계산되는가.
- 여러 오버레이가 겹치면 어떤 순서(트랙 순서 기준 z-order)로 합성되는가.
- 마스킹 대상(예: 얼굴)이 화면 안에서 움직이는데 트래킹이 없으므로, 일부 프레임에서 가려지지 않을 수 있다 — 이를 사용자가 인지하도록 어떻게 안내할지.
- 보조 영상(PIP)의 오디오도 함께 재생할지, 무음 처리할지.

## 범위 조정

- #9는 이미지·보조 영상(PIP) 오버레이(위치·크기·불투명도, 구간 지정)에 집중한다. 정적 마스킹(사용자 흐름 4번, 블러·모자이크)은 #59로 분리했다.

## 결정 사항(#9 구현)

- 클립마다 트랜스폼(`ClipTransform`)을 둔다: 가운데 위치(화면 비율 0~1, 화면비 프리셋을 바꿔도 같은 자리), 배율(화면에 비율을 지켜 꽉 맞춘 크기 대비 5%~400%), 불투명도(0~100%). 기본은 화면에 꽉 맞춘 그대로라 메인 트랙 영상은 손대지 않아도 된다. 분할한 조각도 같은 트랜스폼을 가진다.
- 바꾸는 방법: 인스펙터 "트랜스폼" 탭의 슬라이더(위치 X·Y, 크기, 불투명도, 초기화), 또는 타임라인에서 클립 하나를 고르면 미리보기에 생기는 테두리 — 안을 끌면 옮기고 오른쪽 아래 손잡이를 끌면 크기를 바꾼다. 손을 뗄 때 한 번에 반영하고(실행 취소 한 번), 영상은 다시 합성된 뒤 바뀐다.
- 위쪽 영상 트랙의 영상(PIP)·이미지는 아래 트랙 위에 겹쳐 그리고, 영상의 소리도 함께 들린다. 회전은 이번 범위에 넣지 않았다.
- 정적 마스킹은 #59.

## 결정 사항(#59 정적 마스킹)

- 마스크(`Mask`)는 클립이 아니라 **시퀀스(결과물) 시간**에 붙는다. 눈금자 아래 자막 레인 다음의 **마스크 레인**에 시작·끝이 있는 블록으로 놓고, 두 번 클릭하거나 우클릭해 재생 헤드에 기본 3초로 추가한다. 블록을 끌어 옮기고 양 끝을 끌어 시간을 바꾼다(자막 레인과 같은 조작).
- 영역(`MaskArea`)은 화면 비율(가운데 X·Y, 너비·높이, 왼쪽 위 원점)이라 화면비를 바꿔도 같은 자리다. 화면에 고정되고 피사체를 따라가지 않는다. 마스크를 고르면 미리보기에 점선 테두리가 생겨 안을 끌어 옮기고 오른쪽 아래 손잡이로 너비·높이를 따로 바꾼다. 인스펙터에서 %로도 넣는다.
- 모양: 사각형·타원. 효과: 블러(가우시안)·모자이크(픽셀화), 세기 0~100%(블러 반경·칸 크기).
- 합성: 영상·이미지 층을 모두 그린 뒤, 자막을 그리기 전에 적용한다(자막은 가리지 않는다). 미리보기와 내보내기가 같다. 마스크는 시퀀스 길이에 넣지 않는다(가릴 화면이 있을 때만 의미가 있다).
- 커맨드(`ProjectEditor`): `addMask(at:)`, `updateMask(_:)`(영역·모양·효과·세기, 범위로 맞춤), `setMaskRange(_:start:end:)`, `deleteMask(_:)`.

## 이미지 오버레이 UI/UX

이미지를 가져오는 목적은 최종 영상의 특정 구간 위에 얹는 것이다. 프리미어 프로·Final Cut Pro처럼 미디어 패널은 재료 보관함이고, 얹는 일은 타임라인과 미리보기에서 한다.

1. 배치: 미디어 패널의 이미지를 타임라인의 메인 영상 위 트랙(영상 2 이상)으로 끌어다 놓는다. 위 트랙일수록 화면에서 앞에 그려진다(트랙 순서 = z-order). 재생 헤드 위치에 오버레이로 넣는 단축키도 둔다(Final Cut의 연결 클립처럼).
2. 구간: 이미지 클립의 앞뒤 끝을 끌어 보이는 구간을 정한다. 처음 놓을 때 길이는 `MediaAsset.stillImageDuration`(5초)이다.
3. 위치·크기·불투명도: 미리보기에서 오버레이를 선택하면 테두리 손잡이로 바로 끌어 조정하고, 정확한 값은 인스펙터 "트랜스폼" 탭에서 숫자로 넣는다.
4. 확인·출력: 미리보기에서 합성 결과를 재생하고, 내보내기에 그대로 반영한다.

## 로드맵

앞 단계가 뒤 단계의 전제다. 이 순서대로 이슈 우선순위와 일정을 맞춘다.

| 단계 | 내용 | 이슈 |
|---|---|---|
| 0 | 이미지 가져오기·정리·미리보기(정지 이미지) | #1, #50 |
| 1 | 미디어 패널 → 타임라인 끌어다 놓기, 영상 트랙 여러 개 | #3 클립 이어붙이기 |
| 2 | 시퀀스 재생: 미리보기가 원본(소스 모니터)이 아니라 편집 결과(프로그램 모니터)를 보여준다 | #5 미리보기/재생 |
| 3 | 클립 이동과 앞뒤 끝 끌기(구간 조정) | #2 클립 자르기(트림) |
| 4 | 오버레이 합성: 위 트랙 이미지를 아래 영상 위에 그린다 | #9 |
| 5 | 위치·크기·불투명도: 인스펙터 숫자 입력 + 미리보기 손잡이 | #9 |
| 6 | 내보내기에 합성 반영 | #6 내보내기 |
| 이후 | 이미지 페이드 인/아웃, 스티커, 보조 영상(PIP), 정적 마스킹 | #8, #9 |

설계상 미리 정해야 할 것:

- 이미지 클립 길이: 지금 `Clip`은 원본 길이 안에서 자르는 영상 기준이다. 이미지 클립은 원본 길이 제한 없이 늘릴 수 있어야 해서 1~3단계에서 클립 규칙을 바꾼다.
- 미리보기 역할: 오버레이를 확인하려면 편집 결과를 보여주는 프로그램 모니터(2단계)가 먼저 있어야 한다.
- MCP 원칙: 오버레이도 `ProjectEditor` 커맨드로 먼저 만든다. 예: `addOverlay(assetID:at:duration:track:)`, `setTransform(_:for:)`. 에이전트가 "3초~8초에 로고를 오른쪽 위에 얹어 줘"를 화면 없이 실행할 수 있어야 한다.

## 관련 커맨드/쿼리

- 커맨드(`ProjectEditor`): `placeAsset(_:onTrack:at:)`, `setTransform(_:for:)`, `addMask(at:)`, `updateMask(_:)`, `setMaskRange(_:start:end:)`, `deleteMask(_:)`
- 쿼리: `EditSequence.masks`

## 미정 사항

- 오버레이 여러 개를 겹칠 때 z-order 제어 UX
- 자유형 마스크 모양
- 보조 영상(PIP) 오디오 기본 처리 방식(무음 vs 믹스)
- 동적 오브젝트 트래킹(피사체를 따라 움직이는 마스킹)은 낮은 우선순위 보류 항목 — [기능명세서 보류 섹션](../video-editing-functional-spec.md#보류추후-논의-기능) 참고
