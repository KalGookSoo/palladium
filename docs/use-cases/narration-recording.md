# 내레이션 녹음(더빙) 유즈케이스

## 목적

사용자는 영상을 재생하면서 동시에 마이크로 내레이션/더빙을 녹음하고, 녹음된 오디오가 자동으로 프로젝트에 추가되어 바로 편집 가능한 클립이 되게 한다. 재생-녹음 간 정밀 자동 싱크 보정은 하지 않는다 — 대신 결과 클립을 녹음 시작 시점에 배치해두고, 정확한 싱크는 기존 트림/클립 이동 기능으로 사용자가 직접 맞춘다. 헤드폰/이어폰이 연결된 경우, 스피커는 계속 음소거한 채로 원본 오디오를 헤드폰에만 들려주는 헤드폰 모니터링을 지원한다.

## 사용자 흐름

1. 사용자가 미리보기 플레이어에서 녹음 모드를 켠다(마이크 권한 최초 1회 요청).
2. 재생 헤드를 원하는 시작 지점에 두고 녹음을 시작하면, 스피커의 원본 오디오는 자동으로 음소거되고 영상이 재생되는 동시에 마이크 입력이 캡처된다 — 스피커로 재생되는 원본 소리가 마이크에 함께 수음되는 것을 막기 위함이다.
   - 이때 헤드폰/이어폰이 연결돼 있으면, 원본 오디오는 스피커 대신 헤드폰으로만 들린다(마이크에는 새어 들어가지 않음) — 헤드폰 모니터링.
   - 헤드폰/이어폰이 연결돼 있지 않으면, 원본 오디오 없이(무음 상태로) 화면만 보며 녹음한다.
3. 녹음을 멈추면 캡처된 오디오가 파일로 저장되고, 자동으로 미디어 패널에 가져와진다([미디어 가져오기](media-import.md)의 가져오기 커맨드 재사용).
4. 같은 결과물이 녹음 시작 시점의 타임라인 위치에 새 오디오 클립으로 자동 배치된다([클립 이어붙이기](joining-clips.md)의 배치 커맨드 재사용).
5. 재생-녹음 간 하드웨어 지연으로 싱크가 살짝 어긋나면, 사용자가 기존 트림/클립 이동 기능으로 위치를 손으로 맞춘다([클립 자르기(트림)](trimming.md) 참고).

## 수용 기준

- 녹음 중에도 영상이 끊김 없이 재생된다.
- 녹음을 멈추면 결과 오디오 파일이 자동으로 미디어 패널에 추가된다.
- 같은 결과 클립이 녹음 시작 시점의 재생 헤드 위치에 자동으로 배치된다.
- 녹음 중에는 스피커의 원본 오디오가 항상 자동으로 음소거된다 — 사용자가 선택할 수 있는 옵션이 아니라, 스피커 소리가 마이크에 수음되는 것을 막기 위한 필수 동작이다.
- 헤드폰/이어폰이 연결된 상태로 녹음을 시작하면, 원본 오디오가 헤드폰으로만 들린다(스피커는 여전히 음소거).
- 헤드폰/이어폰이 연결돼 있지 않으면 원본 오디오 재생 없이 녹음이 진행되며, 이 경우도 정상 동작이다(오류로 취급하지 않는다).
- 배치된 클립은 기존 트림/클립 이동 기능으로 자유롭게 위치를 조정할 수 있다 — 정밀 자동 싱크 보정은 의도적으로 범위 밖이다.

## 엣지 케이스

- 마이크 권한이 거부된 상태에서 녹음을 시도하면 어떻게 안내하는가.
- 녹음 중 재생이 타임라인 끝에 도달하면 녹음도 자동으로 멈추는가.
- 같은 위치에 이미 다른 오디오 클립이 있으면 겹쳐서 배치되는가, 새 트랙에 배치되는가.
- 녹음 도중 시스템 알림음이 울리거나 다른 앱이 마이크를 점유하면 어떻게 되는가.
- 녹음 도중 헤드폰이 연결되거나 연결 해제되면(오디오 출력 장치 변경) 모니터링을 즉시 전환하는가, 녹음을 멈춰야 하는가.
- 블루투스 헤드폰은 자체 전송 지연이 있어 모니터링 소리가 실제 화면보다 늦게 들릴 수 있다 — 이 지연이 녹음 자체의 싱크에는 영향을 주지 않는지(모니터링은 참고용일 뿐 실제 캡처 타이밍과는 무관함을 사용자에게 알릴 필요가 있는지).

## 관련 커맨드/쿼리

- 커맨드: `startNarrationRecording(at:)`(스피커 음소거·헤드폰 모니터링 라우팅은 내부에서 항상 자동 수행), `stopNarrationRecording()`
- 쿼리: `isRecording() -> Bool`, `recordingElapsedTime() -> TimeInterval`, `isHeadphonesConnected() -> Bool`

## 미정 사항

- 녹음 결과를 새 오디오 트랙에 배치할지, 기존 트랙의 빈 구간에 배치할지
- 마이크 입력 레벨(볼륨 미터) 표시 여부
- 하드웨어 재생-녹음 지연에 대한 고정 오프셋 보정을 추후 추가할지(지금은 하지 않기로 결정 — 수동 싱크로 충분하다고 판단)
- 녹음 도중 헤드폰 연결 상태가 바뀔 때의 정확한 처리 방식(자동 전환 vs 녹음 중단 후 안내)
