# 프로젝트 저장/불러오기 유즈케이스

## 목적

사용자는 편집 중인 작업을 프로젝트로 저장하고, 나중에 다시 불러와 이어서 작업한다. 하나의 프로젝트 안에 여러 결과물(통합본 + 여러 하이라이트)을 시퀀스 단위로 나눠 관리한다.

## 사용자 흐름

1. 사용자가 새 프로젝트를 만들면, 빈 타임라인(시퀀스) 하나로 시작한다.
2. 작업 내용(가져온 클립, 타임라인 구성, 자막, 적용한 이펙트 등)이 자동 저장되거나, 명시적으로 저장한다.
3. 통합본 외에 별도 하이라이트가 필요하면, 같은 프로젝트 안에 새 시퀀스를 추가해 독립적으로 구성한다.
4. 앱을 종료했다가 다시 열면, 마지막 상태(모든 시퀀스, 클립 배치, 재생 위치 등)가 그대로 복원된다.
5. 여러 시퀀스 중 하나를 선택해 전환하며 작업한다.

## 수용 기준

- 프로젝트를 저장/재개할 수 있고, 재개 시 클립 배치·트림·자막·이펙트가 그대로 복원된다.
- 프로젝트 파일은 SwiftData 기반 자체 포맷으로 저장된다(다른 NLE와의 상호운용성은 요구사항이 아님 — [기능명세서](../video-editing-functional-spec.md) 공통 개념 참고).
- 한 프로젝트 안에 여러 시퀀스를 만들 수 있고, 시퀀스 간 전환이 클립 데이터를 공유한다(같은 클립을 여러 시퀀스에서 재사용 가능).
- 시퀀스를 삭제해도 프로젝트 패널의 원본 클립은 남아있다.
- 앱이 예기치 않게 종료돼도 마지막 자동 저장 시점까지는 복구된다.

## 엣지 케이스

- 시퀀스 하나에서만 쓰던 클립을 프로젝트 패널에서 삭제하면, 그 클립을 참조하던 시퀀스는 어떻게 되는가.
- 프로젝트 파일이 다른 Mac으로 옮겨졌는데 원본 미디어 파일 경로가 달라진 경우(파일 재연결 흐름 필요) — [파일 접근 권한(샌드박스)](../file-access-and-sandboxing.md) 참고.
- 자동 저장 중 앱이 강제 종료되면 프로젝트 파일이 손상되지 않는지.

## 관련 커맨드/쿼리

- 커맨드: `createProject()`, `saveProject()`, `addSequence(name:)`, `deleteSequence(id:)`, `relinkMedia(clip:newURL:)`
- 쿼리: `sequences() -> [Sequence]`, `lastSavedAt() -> Date`, `unresolvedMediaReferences() -> [Clip]`

## 미정 사항

- 자동 저장 주기/방식(매 변경마다 vs 주기적)
- 파일 재연결(원본 경로가 바뀐 경우) UX
