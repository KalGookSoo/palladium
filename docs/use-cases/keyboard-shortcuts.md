# 단축키 유즈케이스

## 목적

사용자는 마우스/트랙패드 없이도 재생·트림 같은 핵심 조작을 빠르게 할 수 있도록 고정된 기본 단축키를 제공받고, 어떤 단축키가 있는지 쉽게 알 수 있다. 사용자가 단축키를 직접 재매핑하는 커스텀 키맵은 이번 범위에서 제외한다([기능명세서 보류 섹션](../video-editing-functional-spec.md#보류추후-논의-기능) 참고).

## 사용자 흐름

1. 사용자가 툴바나 인스펙터의 버튼 위에 마우스를 올리면(hover), 툴팁에 해당 동작의 단축키가 함께 표시된다(예: "재생/일시정지 (Space)").
2. 메뉴 바의 각 메뉴 항목에도 표준적으로 단축키가 표시된다(SwiftUI `Commands`가 기본 제공하는 방식).
3. 전체 단축키가 궁금하면 도움말에서 단축키 가이드를 열어 목록을 한 번에 확인한다.

## 수용 기준

- 재생/일시정지, 프레임 단위 이동, 트림 확정 등 핵심 조작에 고정된 기본 단축키가 있다.
- 툴바·인스펙터의 관련 버튼에는 툴팁으로 단축키가 함께 노출된다.
- 도움말(또는 가이드 문서)에서 전체 단축키 목록을 확인할 수 있다.
- 사용자가 단축키를 직접 재매핑하는 기능은 제공하지 않는다 — 항상 고정된 기본값이다.

## 결정 사항

- 단축키와 설명은 `ShortcutGuide` 한곳에서 관리하고, 툴팁과 단축키 목록 창이 같은 내용을 보여준다. 툴팁은 "이름 — 설명 (단축키)" 형식이다(예: "재생/일시정지 — 미리보기를 재생하거나 멈춥니다 (Space)"). 단축키가 없는 버튼은 "이름 — 설명"만 보여준다.
- 기본 단축키

| 묶음 | 동작 | 단축키 |
|---|---|---|
| 파일 | 프로젝트 목록 열기 / 새 프로젝트(시작 창) / 저장 / 닫기 | ⇧⌘1 / ⌘N / ⌘S / ⌘W |
| 파일 | 가져오기 / 내보내기 / 여러 시퀀스 내보내기 | ⌘I / ⌘E / ⇧⌘E |
| 보기 | 미디어 패널 / 타임라인 / 인스펙터 보기·가리기 | ⌃⌘S / ⌥⌘2 / ⌥⌘I |
| 보기 | 타임라인 확대 / 축소 | ⌘= / ⌘- |
| 재생 | 재생/일시정지 / 이전 프레임 / 다음 프레임 | Space / ← / → |
| 타임라인 | 고른 자막 옮기기(0.5% / ⇧ 5%) — 자막을 골랐을 때만, 아니면 ←/→는 프레임 이동 | ←/→/↑/↓, ⇧+방향키 |
| 재생 | 내레이션 녹음 시작/정지 | R |
| 편집 | 실행 취소 / 다시 실행 | ⌘Z / ⇧⌘Z |
| 편집 | 이름 변경(타임라인 클립 별칭, 미디어 패널에 포커스가 있으면 원본 이름) | F2 |
| 편집 | 클립 편집…(고른 클립, 미디어 패널에 포커스가 있으면 항목 — 트림·크롭 탭이 있는 창) | ⌘T |
| 트림 창 | 잡은 손잡이 0.1초 / 1초 옮기기, 고른 구간 재생 | ↑/↓, ⇧↑/↓, Space |
| 타임라인 | 삭제 / 리플 삭제 / 클립 분할(편집 메뉴) / 모든 클립 선택 / 선택 해제 | ⌫ / ⇧⌫ / ⌘B / ⌘A / Esc |
| 타임라인 | 잘라내기 / 복사 / 붙여넣기 / 복제(편집 메뉴) | ⌘X / ⌘C / ⌘V / ⌘D |
| 타임라인 | 선택에 더하기·빼기 / 범위 선택 | ⌘ 클릭 / ⇧ 클릭 |
| 타임라인 | 재생 헤드에 마커 추가 / 자막 추가 | M / T |
| 타임라인 | 클립 끝을 끌 때 정밀 조정 | ⌥ 누른 채 끌기 |
| 도움말 | palladium 도움말 / 단축키 목록 | ⇧⌘/ / ⌘/ |

- 재생·타임라인 단축키(Space, ←/→/↑/↓, ⌫, ⇧⌫, ⌘A, ⌘C, ⌘X, ⌘V, Esc, M, T, R)는 메뉴 단축키로 두지 않고 편집 창에서 키 입력을 직접 받는다(`EditorKeyMonitor`). 클립 우클릭 메뉴에는 단축키를 표시만 한다. 수식키가 있는 클립 분할(⌘B)은 편집 메뉴 항목이다. 메뉴 단축키로 두면 검색창·이름 입력란에서 띄어쓰기와 커서 이동까지 가로채기 때문이다. 입력란을 편집 중이거나 미리보기에 원본이 열려 있지 않으면 키를 그대로 넘기고, 편집 창이 여러 개면 앞에 있는 창만 반응한다.
- 도움말 > 단축키 목록(⌘/) 또는 palladium 도움말(⇧⌘/)에서 전체 목록을 보고 검색한다(#20).

## 엣지 케이스

- 앱 단축키가 macOS 시스템 전역 단축키(예: 스크린샷, Spotlight)와 겹치면 어떻게 되는가.
- 아이콘만 있고 텍스트 라벨이 없는 툴바 버튼의 단축키 정보를 VoiceOver 사용자에게 어떻게 전달하는가.

## 미정 사항

- 최초 실행 시(온보딩) 단축키 가이드를 자동으로 한 번 보여줄지 여부 — [도움말](help.md) 참고
