# 이펙트(기본 색보정) 유즈케이스

## 목적

사용자는 어둡게 찍힌 장면을 밝히거나 클립끼리 색감을 대충 맞춘다(#61). 인스펙터 "이펙트" 탭의 "준비 중" 화면을 실제 기능으로 바꾼다.

## 사용 장면

- 실내라 어둡게 나온 노래방 영상을 밝게 하기
- 두 카메라로 찍은 클립의 채도 맞추기
- 회상 장면을 흑백(채도 0)으로 만들기

## 사용자 흐름

1. 클립(영상·이미지)을 고르고 인스펙터 영상 탭의 이펙트 섹션을 연다(#90 전에는 이펙트 탭).
2. 밝기·대비·채도 슬라이더를 움직이면 미리보기에 바로 보인다. 손을 떼는 순간 한 번의 편집으로 기록된다(실행 취소 한 번).
3. 슬라이더 옆 ↺로 그 값만, "초기화"로 셋 다 원래대로 돌린다.
4. 이펙트가 걸린 클립은 타임라인에서 이름 옆에 작은 표시가 생긴다.
5. 여러 클립을 고르고 값을 바꾸면 모두에 같은 값이 들어간다(색감 맞추기).

## 수용 기준

- 기본값은 원본 그대로(밝기 0, 대비 1, 채도 1)이고, 내보내기 결과가 미리보기와 같다.
- 범위: 밝기 -0.5 ~ +0.5, 대비 0.5 ~ 1.5, 채도 0 ~ 2(0이면 흑백).
- 클립을 나누면 두 조각 모두 같은 값을 갖고, 복사·붙여넣기(#62)에도 따라간다. 프로젝트에 저장된다.
- 오디오 클립을 고르면 "오디오 클립에는 영상 이펙트가 없습니다"를 보여준다.

## 결정 사항

- 이번에는 밝기·대비·채도 셋만 한다. 노출·색온도, 스코프·LUT는 #69, 블러 같은 필터는 #68에서 이 탭에 더한다(#68 결정 사항은 아래).
- 지금 화면에만 있고 동작하지 않는 "필터" 선택 칸은 지운다.
- 합성기(`LayerCompositor`)에서 Core Image `CIColorControls`로 적용한다. 네트워크가 필요 없다. 화면에 놓기 전(위치·크기를 바꾸기 전) 원본 이미지에 걸어 화면 밖 투명한 곳은 건드리지 않고, 기본값이면 건너뛴다. 미리보기와 내보내기가 같은 합성을 쓰므로 결과가 같다.
- 슬라이더는 트랜스폼과 같이 손을 뗄 때 한 번의 편집으로 반영하고, 그때 미리보기가 바뀐다(끄는 동안은 숫자만 바뀐다). 끄는 동안 미리보기를 계속 다시 그리는 방식은 합성을 자주 새로 만들어야 해 하지 않았다.
- 여러 클립을 고르면 인스펙터는 "클립 N개 선택"과 함께 이펙트만 보여준다. 값은 고른 영상·이미지 클립 중 첫 클립(트랙·시각 순) 기준으로 보이고, 바꾸면 고른 영상·이미지 클립 모두에 셋 다 같은 값이 들어간다(오디오 클립은 건너뛴다). 고른 클립이 모두 오디오면 "영상 이펙트 없음"을 보여준다.
- 타임라인 표시: 색보정이 기본값이 아니면 클립 이름 옆에 작은 이펙트 아이콘(`camera.filters`)을 그린다.
- 저장: 클립 레코드에 밝기·대비·채도를 기본값(0·1·1)과 함께 더해 기존 프로젝트도 그대로 열린다. 범위 밖 저장값은 불러올 때 범위 안으로 맞춘다.

## 결정 사항(#68 필터형 이펙트)

- 필터 여덟 가지를 고른 목록으로 둔다: 블러, 선명하게, 비네트, 흑백(누아르), 세피아, 픽셀화, 빛 번짐, 볼록 렌즈(왜곡). 모두 Core Image 내장 필터라 기기 안에서 동작한다. 이펙트 섹션의 색보정 아래 "필터 추가" 메뉴로 더한다.
- 클립마다 여러 개를 쌓고(같은 종류를 여러 번도 가능), 위에서부터 차례로 적용한다. 줄마다 세기(0~100%, 손을 뗄 때 반영)·위로·아래로·빼기 버튼. 새 필터의 세기는 50%.
- 적용 순서: 색보정 → 필터(쌓은 순서) → 크롭 → 화면에 놓기(위치·크기·회전·불투명도). 화면에 놓기 전 원본 이미지에 걸어 화면 밖 투명한 곳은 건드리지 않는다. 세기는 이미지 짧은 변에 비례해 원본 해상도와 상관없이 같은 느낌이다. 흐리기·픽셀화·빛 번짐·볼록 렌즈는 가장자리를 늘여 그린 뒤 원래 크기로 잘라 가장자리가 투명하게 번지지 않는다. 세기 0은 원본 그대로다.
- 여러 클립을 고르면 색보정처럼 첫 영상·이미지 클립의 필터 목록이 보이고, 바꾸면 고른 영상·이미지 클립 모두에 같은 목록이 들어간다. 타이틀(#76)에도 걸 수 있다.
- 나누기·복사·붙여넣기에 따라가고, 이펙트 표시(`camera.filters`)는 색보정이나 필터가 있으면 켜진다. 저장: 클립 레코드 `filtersData`(JSON, 옵셔널).
- 필터 세기를 시간에 따라 바꾸는 키프레임은 하지 않았다(#67은 트랜스폼·음량만).

## 결정 사항(#70 크로마키)

- 인스펙터 영상 탭 "크로마키" 섹션: 켜고 끄기, 키 색(초록·파랑 버튼, 색 상자, 스포이트), 허용 범위·부드러움·색 번짐 제거 슬라이더(손을 뗄 때 반영). 기본값은 초록, 허용 범위 30%, 부드러움 10%, 색 번짐 제거 50%.
- 스포이트는 macOS 기본 색 채집기(`NSColorSampler`)라 미리보기에 보이는 배경을 눌러 고른다(새로 그리는 확대 화면을 만들지 않음).
- 거리는 밝기를 뺀 색(YCbCr의 Cb·Cr)으로 잰다 — 그림자 진 초록도 같은 색으로 보고 빠지게 하기 위해서다. 허용 범위 안은 투명, 부드러움 폭에서 부드러운 계단(smoothstep)으로 불투명해진다. 색 번짐 제거는 키 색 쪽으로 기운 색 성분을 그만큼 덜어 낸다(밝기는 그대로).
- 합성기에서 Core Image 색 입방체(32칸, sRGB, 미리 곱한 알파)로 적용해 미리보기·내보내기가 같다. 설정마다 한 번만 만들어 캐시한다. 적용 순서는 크로마키 → 색보정 → 필터 → 크롭 → 화면에 놓기(원래 색으로 배경을 고르기 위해 가장 먼저).
- 위 영상 트랙 클립에 켜면 아래 트랙이 비친다. 메인 트랙 클립에 켜면 빠진 자리가 검게 보인다. 여러 클립을 고르면 고른 영상·이미지 클립 모두에 같은 설정이 들어간다.
- 저장: 클립 레코드 `chromaKeyData`(JSON, 옵셔널). 이펙트 표시에 반영한다.

## 관련 커맨드/쿼리

- 커맨드(`ProjectEditor`, 구현): `setChromaKey(_:for:)`(#70), `setFilters(_:for:)`(#68, 실행 취소 이름 "필터"), `setColorAdjustment(_:for:)` — 여러 클립에 한 번에 적용하고 범위로 맞춘다. 실행 취소 이름은 "색보정".
- 도메인(구현): `Clip.colorAdjustment: ColorAdjustment`(`brightness`, `contrast`, `saturation`, `isDefault`, `clamp()`), 합성 `LayerCompositor.applying(_:to:)`

## 미정 사항

- 노출·색온도 추가 시점(#69와 함께 검토)
