# 미디어 가져오기 유즈케이스 (초안)

## 목적

사용자는 영상/음악 파일을 프로젝트로 가져와 타임라인에 배치한다.

## 기대하는 동작(초안)

- 드래그&드롭으로 파일을 가져올 수 있다.
- 파일 선택 대화상자로도 가져올 수 있다.
- 여러 파일을 한 번에 가져올 수 있다.
- 지원하지 않는 포맷은 안내 메시지를 보여준다.

## 미정 사항

- 지원 포맷/코덱 범위 — [지원 미디어 포맷/코덱](../media-format-support.md) 참고
- 가져온 파일의 원본 위치 참조 방식(복사 vs 참조) — 샌드박스 권한과 연결됨, [파일 접근 권한](../file-access-and-sandboxing.md) 참고
- 대용량 파일/긴 영상 가져올 때 로딩 UX
