# 미디어 가져오기 유즈케이스

## 목적

사용자는 영상/음악/이미지 파일을 프로젝트로 가져와 정리하고, 필요할 때 타임라인에 배치한다.

## 사용자 흐름

1. 사용자가 Finder에서 파일을 앱 창으로 드래그&드롭하거나, 파일 선택 대화상자로 하나 이상의 파일을 고른다.
2. 앱이 각 파일의 포맷/코덱을 확인한다([지원 미디어 포맷/코덱](../media-format-support.md) 참고).
3. 지원하는 파일은 프로젝트 패널에 추가되고, 자동으로 썸네일/길이 같은 메타데이터를 표시한다.
4. 원본 해상도가 4K 이상이면 자동으로 프록시(저해상도 대체 파일)를 생성해 연결한다 — 그 이하 해상도는 원본을 그대로 쓴다([환경설정](preferences.md)에서 이 임계값을 바꿀 수 있다).
5. 지원하지 않는 파일은 목록에 추가하지 않고, 어떤 파일이 왜 실패했는지 안내한다.
6. 사용자는 프로젝트 패널에서 클립을 폴더(빈)로 분류하거나, 레이블/색상 태그·별점을 매긴다.
7. 클립이 많아지면 이름/태그/레이블로 검색·필터링해 원하는 클립을 찾는다.
8. 프로젝트 패널의 클립을 타임라인으로 드래그해 배치한다(실제 배치 이후 동작은 [클립 이어붙이기](joining-clips.md) 참고).

## 수용 기준

- 드래그&드롭과 파일 선택 대화상자 두 경로 모두로 가져오기가 가능하다.
- 여러 파일을 한 번에 선택해 가져올 수 있다.
- 가져온 클립은 폴더로 분류하거나 레이블/색상 태그/별점을 매길 수 있다.
- 클립 이름/태그/레이블 기준으로 검색·필터링할 수 있다.
- 지원하지 않는 포맷을 가져오려 하면, 어떤 파일이 문제인지 구체적으로 안내한다(일부만 실패해도 나머지는 정상 처리).
- 4K 이상 해상도의 원본은 가져올 때 자동으로 프록시(저해상도 대체 파일)를 생성해 연결한다(기본값) — 그 이하 해상도는 원본을 그대로 사용해 불필요한 대기시간·디스크 사용을 만들지 않는다.
- 프록시 생성 여부를 가르는 해상도 임계값은 [환경설정](preferences.md)에서 바꿀 수 있다.

## 결정 사항

- 원본은 복사하지 않고 제자리에서 참조한다. 앱을 다시 켜도 열 수 있도록 원본마다 security-scoped bookmark를 함께 저장한다([파일 접근 권한](../file-access-and-sandboxing.md)).
- 이미 가져온 파일(같은 경로)을 다시 가져오면 추가하지 않고 기존 원본을 선택한 뒤, 몇 개를 건너뛰었는지 알린다.
- 파일 단위로만 가져온다. 폴더를 끌어오면 "폴더는 가져올 수 없습니다"로 안내한다.
- 가져온 원본은 미디어 패널의 "분류 안 됨"에 추가되고, 저장하지 않은 변경이 된다(파일 > 저장으로 반영).
- 이미지는 길이가 없어 타임라인에 처음 놓을 때 5초로 놓는다.
- 정리 정보는 색상 레이블(Finder 태그와 같은 일곱 색 중 하나), 태그(쉼표로 나눠 입력하는 자유 텍스트), 별점(0~5)이다. 미디어 패널에서 원본을 우클릭해 바꾸고, 행에는 색 점과 "길이 · 별점 · 태그"로 보여준다.
- 검색창은 이름과 태그를 함께 찾는다. 검색창 아래 필터 메뉴로 색상 레이블(여러 개 고르면 그중 하나)과 최소 별점을 고르며, 모든 조건을 만족하는 원본만 보인다.
- 4K 이상 원본의 프록시 생성은 환경설정(#19)의 임계값과 엮여 있어 별도 이슈로 분리한다.

## 엣지 케이스

- 같은 파일을 중복으로 가져오면 기존 원본을 재사용한다(위 결정 사항).
- 가져오는 도중 원본 파일이 이동/삭제되면 어떻게 되는가.
- 프록시 생성 중 원본으로 미리 재생/배치를 시도하면 어떻게 되는가.

## 관련 커맨드/쿼리

- 커맨드: `importMedia(urls:)`, `assignFolder(clip:folder:)`, `setLabel(clip:label:)`, `generateProxy(clip:)`
- 쿼리: `search(query:) -> [Clip]`, `unsupportedReason(url:) -> String?`, `shouldGenerateProxy(for:) -> Bool`(해상도 임계값과 비교해 자동 생성 여부를 판단)

## 미정 사항

- 대용량 파일/긴 영상 가져올 때 로딩 UX(백그라운드 처리 여부, 진행률 표시)
- 4K 기준값이 코덱/프레임레이트에 따라서도 조정돼야 하는지(예: 4K 30fps는 문제없지만 4K 60fps는 버벅이는 기기가 있을 수 있음)
