# 미리보기/재생 유즈케이스

## 목적

사용자는 편집 중인 타임라인을 실제 결과물처럼 재생하며 확인한다.

## 사용자 흐름

1. 사용자가 재생 헤드를 원하는 위치로 옮긴다(클릭, 드래그, 정밀 시간 입력).
2. 재생 버튼을 눌러 현재 위치부터 타임라인을 재생한다.
3. 타임라인을 좌우로 드래그해(스크러빙) 원하는 지점을 빠르게 훑어본다.
4. 프레임 단위로 한 프레임씩 앞/뒤로 이동해 정확한 지점을 찾는다.
5. 트림/이펙트/트랜지션 등 편집 결과가 미리보기에 실시간으로 반영되는지 확인한다.

## 수용 기준

- 재생/일시정지/스크러빙이 끊김 없이 동작한다(일반적인 편집 규모 기준).
- 프레임 단위 이동으로 정확히 한 프레임씩 앞/뒤로 이동한다.
- 멀티트랙 구성(영상+오디오+자막 등)이 미리보기에서 실제 내보내기 결과와 동일하게 합성되어 보인다.
- 트림/트랜지션/이펙트를 적용한 직후에도 미리보기가 최신 상태를 반영한다(별도 새로고침 불필요).

## 엣지 케이스

- 고해상도(4K 이상) 원본을 프록시 없이 재생하면 스크러빙이 버벅이는 경우 — [미디어 가져오기](media-import.md)의 프록시 기능과 연동 필요.
- 트랜지션 구간을 스크러빙할 때 두 클립이 정확한 비율로 합성되어 보이는지.
- 재생 중 클립을 트림하면 재생이 어떻게 이어지는지(일시정지 후 갱신 vs 즉시 반영).

## 관련 커맨드/쿼리

- 커맨드: `seek(to:)`, `play()`, `pause()`, `stepFrame(direction:)`
- 쿼리: `currentTime() -> CMTime`, `isPlaying() -> Bool`, `renderedFrame(at:) -> CGImage`

## 결정 사항

- 미리보기는 **시퀀스 미리보기 하나**만 둔다. 원본 전용 뷰(소스 모니터)와 [원본 | 시퀀스] 전환은 두지 않는다 — 원본은 통째로 타임라인에 넣고 거기서 자른다.
- 예외(2026-10-06 결정): 영상·오디오 하나를 QuickTime처럼 트림하는 **트림 시트**(#81)에서만 그 클립의 원본 전체 구간을 보여준다. 정확히 줄이고 늘리려면 지금 쓰지 않는 앞뒤 구간이 보여야 하기 때문이다. 일반 원본 모니터와 [원본 | 시퀀스] 전환은 여전히 두지 않는다.
- 넣기 전에 원본을 확인할 때는 미디어 패널 우클릭 > 훑어보기로 macOS 훑어보기(Quick Look) 창을 연다. 두 번 누르기는 영상·오디오면 트림 시트(#81 — 구간을 보며 확인하고 파생 항목을 만든다), 이미지면 훑어보기를 연다(2026-10-06 변경: 처음에는 두 번 누르기가 훑어보기였다). Space는 시퀀스 재생/일시정지이므로 훑어보기에 쓰지 않는다.
- 두 단계로 진행한다: 1) 영상 1 + 소리 재생, 재생 헤드 연동, 편집 즉시 반영, 원본 미리보기를 훑어보기로 대체 2) 여러 영상 트랙 겹쳐 그리기(#9와 함께).
- 1단계 구현: `SequenceComposer`가 시퀀스를 AVFoundation 합성(`AVComposition` + `AVVideoComposition`)으로 만든다. 메인 영상 트랙(맨 아래 영상 트랙)의 영상과 그 소리, 오디오 트랙들을 넣고, 클립마다 원본(회전 포함)을 툴바의 화면비 프리셋 크기(짧은 변 1080) 안에 비율을 지켜 가운데 맞춘다. 빈 구간은 검은 화면이다. 같은 합성을 내보내기(#6)에도 쓴다.
- 편집(놓기·옮기기·자르기·삭제)이나 화면비가 바뀌면 잠깐(0.15초) 기다렸다 다시 합성하고, 보던 위치를 이어 간다.
- 재생 헤드와 미리보기는 서로 따라간다: 재생 중에는 재생 헤드가 움직이고, 눈금자·마커로 재생 헤드를 옮기면 미리보기가 그 위치로 간다. Space·←/→도 시퀀스에 적용된다.
- 재생 헤드·눈금자(#79): 눈금자는 두 줄이다 — 위 줄은 시간 글자, 아래 줄은 눈금·마커·재생 헤드 머리(▼). 머리에 마우스를 올리면 좌우 이동 커서가 되고 끌면 재생 헤드가 따라온다. 눈금자 빈 곳을 누르거나 끌어도 그 시각으로 간다. 눈금자에 마우스를 올리면 그 위치 시각이 위 줄에 작은 배지로 보이고(정적인 시스템 툴팁은 마우스를 따라 바뀌지 않아 배지로 그린다), 끄는 동안에는 재생 헤드 시각이 강조색 배지로 보인다. 시각은 분:초.소수(확대해 초당 100pt 이상이면 소수 둘째 자리, 아니면 첫째 자리, 버림)로 보여준다. 재생 헤드 가까이(30pt)의 시간 글자는 흐리게 그린다. 트랙 영역을 지나는 세로선은 누를 수 없게 두어 클립 끌기·트림을 막지 않는다.
- 2단계 구현(#9와 함께): 모든 영상 트랙과 이미지 클립을 층으로 겹쳐 그린다(아래 트랙이 먼저, 위 트랙이 그 위). 그리기는 Core Image 합성기(`LayerCompositor`, AVFoundation 사용자 정의 합성기)가 하고, 클립 경계마다 구간을 나눠 구간마다 걸친 층을 쌓는다. 모든 영상 트랙의 소리도 함께 넣는다. 미리보기와 내보내기가 같은 합성기를 쓴다.

## 미정 사항

- 프록시 미사용 시 성능 저하를 어떻게 사용자에게 안내할지(자동 프록시 생성 제안 등)
- 스크러빙 시 오디오도 함께 들려줄지(scrub audio) 여부
