# 클립 이어붙이기 유즈케이스 (초안)

## 목적

사용자는 트림된 여러 클립을 순서대로 이어붙여 하나의 결과물(통합본)을 만든다.

## 기대하는 동작(초안)

- 타임라인에서 클립 순서를 자유롭게 바꿀 수 있다.
- 클립 사이는 컷 편집(트랜지션 없음)을 기본으로 한다.
- 여러 개의 "하이라이트"를 만드는 경우, 클립 묶음을 여러 세트로 나눠 각각 별도 결과물로 관리할 수 있다.

## 미정 사항

- 클립 사이 트랜지션 효과 필요 여부(1차 범위에서는 제외 — [기능명세서](../video-editing-functional-spec.md) 참고)
- 여러 하이라이트를 하나의 프로젝트 안에서 관리하는 방식(프로젝트 하나에 여러 "시퀀스"를 둘지, 프로젝트를 여러 개 만들지)
