# 내보내기 유즈케이스 (초안)

## 목적

사용자는 완성된 타임라인을 실제 영상 파일로 내보낸다.

## 기대하는 동작(초안)

- 전체를 하나로 합친 통합본을 내보낼 수 있다.
- 여러 하이라이트를 각각 개별 파일로 내보낼 수 있다.
- 유튜브(16:9)/인스타그램(9:16, 1:1) 등 화면비 프리셋을 고를 수 있다.
- 내보내기 진행 상황을 보여준다.

## 미정 사항

- 내보내기 해상도/비트레이트 프리셋 범위
- 내보내기 포맷(코덱) 범위 — [지원 미디어 포맷/코덱](../media-format-support.md) 참고
