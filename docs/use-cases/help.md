# 도움말 유즈케이스

## 목적

사용자는 앱 밖으로 나가지 않고도 주요 기능 사용법과 전체 단축키 목록을 바로 확인할 수 있다. macOS 정식 Help Book(Spotlight 연동 `.help` 번들)까지는 만들지 않고, 앱 내 도움말 패널로 충분하다고 판단한다.

## 사용자 흐름

1. 사용자가 메뉴 바 `도움말` 메뉴(`Cmd+?`)를 연다.
2. "palladium 도움말"을 선택하면 앱 내 도움말 패널이 열린다.
3. 핵심 기능(가져오기, 트림, 내보내기, 내레이션 녹음 등) 설명과 전체 단축키 목록([단축키](keyboard-shortcuts.md) 참고)을 확인한다.
4. 검색으로 원하는 항목을 빠르게 찾는다.

## 수용 기준

- `도움말` 메뉴에서 앱 내 도움말 패널을 열 수 있다.
- 핵심 기능별 설명과 전체 단축키 목록이 한 곳에 정리돼 있다.
- 도움말 안에서 검색이 가능하다.

## 엣지 케이스

- 기능이 추가/변경될 때마다 도움말 내용이 실제 동작과 어긋나지 않게 유지해야 한다 — `docs/` 문서와 앱 내 도움말 텍스트가 별도로 관리되므로 동기화 부담이 생긴다.

## 관련 커맨드/쿼리

- 쿼리: `helpTopics() -> [HelpTopic]`, `searchHelp(query:) -> [HelpTopic]`

## 미정 사항

- 최초 실행(온보딩) 시 단축키 가이드를 자동으로 한 번 보여줄지, 도움말 메뉴로만 접근하게 할지
- 도움말 콘텐츠를 앱 리소스에 하드코딩할지, `docs/` 문서에서 생성/공유할지
