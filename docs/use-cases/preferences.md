# 환경설정 유즈케이스

## 목적

사용자는 앱 전역 동작(저장, 가져오기, 내보내기 등)의 기본값을 직접 조정할 수 있다. macOS 표준 관례(`Cmd+,`)를 따르는 환경설정 창 하나로, 다른 유즈케이스 문서에 흩어져 있던 "기본값을 어떻게 정할지" 미정 사항들을 정리한다.

## 사용자 흐름

1. 사용자가 메뉴 바 `palladium > 설정...`(`Cmd+,`)으로 환경설정 창을 연다.
2. 자동 저장 주기(즉시 저장 vs 일정 간격)를 조정한다.
3. 프록시 미디어를 자동으로 생성할 해상도 임계값(기본값 4K)을 조정한다([미디어 가져오기](media-import.md) 참고) — 이 값 이상인 원본만 자동으로 프록시가 생성된다.
4. 기본 내보내기 프리셋(포맷/해상도/화면비)을 지정해둔다([내보내기](export.md) 참고).
5. 변경 사항은 즉시 적용된다 — macOS `Settings` 씬 관례대로 별도 저장 버튼은 없다.

## 수용 기준

- 환경설정 창은 `Cmd+,`로 열 수 있다.
- 자동 저장 주기를 조정할 수 있고, 실제 자동 저장 동작에 반영된다.
- 프록시 자동 생성 해상도 임계값(기본값 4K)을 조정할 수 있고, 미디어 가져오기 동작에 반영된다.
- 기본 내보내기 프리셋을 지정할 수 있고, 내보내기 화면에 기본값으로 채워진다.
- 설정 변경은 즉시 저장되고, 앱을 재시작해도 유지된다.

## 결정 사항(#19 1차)

- 환경설정 창은 SwiftUI `Settings` 씬(palladium > 설정…, ⌘,)이고 바꾸면 바로 `UserDefaults`에 저장된다.
- "자동 저장 주기"는 수동 저장(#7)으로 바뀌어 **백업 간격**이 되었다. 30초·1분(기본)·2분·5분·10분 중에서 고르고, 비정상 종료 뒤 복구를 지키려고 "끔"은 두지 않는다. 열려 있는 프로젝트에는 다음 백업부터 반영된다.
- 프록시 임계값(#43)과 기본 내보내기 프리셋(#6)은 그 기능이 생길 때 이 창에 더한다. 그전까지 #19는 열어 둔다.

## 엣지 케이스

- 자동 저장 주기를 "끔"에 가깝게 설정하면, [프로젝트 저장/불러오기](project-management.md)의 "앱이 예기치 않게 종료돼도 복구된다"는 수용 기준과 어떻게 절충하는가.
- 설정 변경이 이미 열려있는 프로젝트에 즉시 반영되는가, 재시작 후에만 반영되는가.

## 관련 커맨드/쿼리

- 커맨드: `updatePreference(key:value:)`
- 쿼리: `preference(key:) -> Value`

## 미정 사항

- 실제로 노출할 설정 항목의 최종 범위(위 3개 외에 더 필요한지)
- 프로젝트별 설정 vs 앱 전역 설정 구분 필요 여부
