# 파일 접근 권한(샌드박스) (초안)

## 목적

macOS App Sandbox 환경에서 사용자가 고른 영상/음악 파일을 읽고, 결과물을 내보낼 위치에 쓸 수 있어야 한다. tempo(iOS, 마이크 녹음 권한만 다룸)에는 없던 고려사항이라 새로 정리한다.

## 검토 방향(초안, 아직 확정 아님)

- App Sandbox 엔타이틀먼트: `com.apple.security.files.user-selected.read-write` 필요 예상(파일 선택 대화상자/드래그&드롭으로 고른 파일에 한해 접근 허용).
- 앱을 재실행해도 이전에 가져온 파일에 다시 접근하려면 **security-scoped bookmark** 저장이 필요(그냥 경로 문자열만 저장하면 재실행 후 접근 권한이 사라짐).
- 내보내기 위치도 사용자가 매번 선택하게 할지, 마지막 내보낸 폴더를 기억해둘지 결정 필요.

## 미정 사항

- 프로젝트 파일 자체를 어디에 저장할지(앱 컨테이너 내부 vs 사용자가 고른 폴더)
- 드래그&드롭으로 폴더째 가져오는 것까지 지원할지(폴더 접근은 파일 단위보다 권한 처리가 더 복잡함)
