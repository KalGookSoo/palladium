# App Store 릴리스 노트 템플릿

App Store Connect > 배포 > iOS 앱 버전 > "새로운 기능(What's New in This Version)" 필드에
그대로 옮겨 적을 사용자 대상 릴리스 노트 템플릿이다. 4000자 제한이 있고, 마크다운·이슈
번호·기술 용어 없이 평범한 문장으로 작성한다.

`.github/RELEASE_TEMPLATE.md`(GitHub 릴리스 노트, 개발자 대상)와 짝을 이루는 문서다 —
릴리스할 때 GitHub 릴리스 노트를 먼저 작성하고, 그중 사용자가 체감할 수 있는 부분만
추려서 이 형식으로 다시 써서 App Store Connect에 옮긴다.

## 버전: vX.Y.Z

(사용자가 체감할 수 있는 변경 사항을 2~5줄로. 예:)

- 애플워치 연동이 더 안정적으로 동작하도록 개선했습니다.
- 알림 큐 사운드 음량을 키웠습니다.
- 자잘한 버그를 수정했습니다.

## 작성 가이드

- 이슈/PR 번호, API 변경 사항, 배포 요구사항, 테스트 체크리스트 등 개발자용 내용은
  넣지 않는다 — 그건 GitHub 릴리스 노트(`.github/RELEASE_TEMPLATE.md`)에 남긴다.
- "수정했습니다", "개선했습니다"처럼 사용자가 이해할 수 있는 표현으로 쓴다.
- 최초 출시(v1.0.0)처럼 이전 버전과 비교할 게 없는 릴리스는 이 필드 자체가 App Store
  Connect UI에 안 보이거나 필수가 아닐 수 있다 — 그럴 땐 비워두거나 "정식 출시했습니다"
  정도로 짧게 적어도 충분하다.
- 로케일마다(현재는 한국어만) 각각 작성한다. 영어 로케일이 추가되면 번역해서 같이 채운다.
