# 지원 미디어 포맷/코덱 (초안)

## 목적

가져오기/내보내기에서 어떤 파일 형식과 코덱을 지원할지 정리한다. AVFoundation 기반 구현을 전제로 한다.

## 검토 방향(초안, 아직 확정 아님)

- 영상 가져오기: `.mp4`, `.mov` 우선 검토(둘 다 AVFoundation이 기본 지원)
- 오디오 가져오기: `.mp3`, `.m4a`, `.wav` 우선 검토
- 내보내기: `.mp4`(H.264) 기본, 필요시 HEVC(H.265) 추가 검토
- 자막: 외부 파일 포맷 지원 여부는 [자막 삽입 유즈케이스](use-cases/subtitles.md)에서 별도 결정

## 미정 사항

- 지원 안 하는 포맷을 가져왔을 때 변환(트랜스코딩) 제공 여부, 아니면 그냥 거부할지
- 코덱별 macOS 버전 호환성 확인 필요(HEVC 하드웨어 인코딩 지원 기기 범위 등)
